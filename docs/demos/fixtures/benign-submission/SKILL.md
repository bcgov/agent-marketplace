# Demo Submission

## Use When
- Demonstrating a small, public workflow candidate.

## Don't Use When
- A production security decision requires domain review.

## Workflow
1. Read the user's public request.
2. Return a concise checklist.

## Rules
- Do not request credentials or access private systems.

## Examples
- "Show me the demo checklist" -> return the checklist.

## Edge Cases
- If the request is ambiguous -> ask for one clarifying detail.

## References
No bundled references are required.
