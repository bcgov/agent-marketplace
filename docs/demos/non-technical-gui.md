# Non-technical GUI path

1. Run `make generate && make docs && make serve`.
2. Open the catalog page without using a repository path or validation command.
3. Search using ordinary language such as **help secure a repository**.
4. Filter by specialty, capability, owner, lifecycle, and review status.
5. Open a result, read the plain-language purpose and warnings, and follow the
   guided install instructions only after confirming what will be installed.
6. Use the visible no-match/request link if no result fits.

The page should be keyboard navigable, use semantic headings, expose warning
text without color alone, and show the same inventory as the companion finder.
