# Follow the no-match path

Ask the finder:

> Find an extension that automatically operates a production MCP server and
> rotates credentials.

The expected result is not an installation. The finder should explain that no
active MVP package matches the request and that MCP, automatic execution, and
secret-handling runtime behavior are deferred. Offer one of:

- a marketplace request with the desired outcome and constraints;
- `bcgov-create-extension` for a portable draft;
- a direct maintainer or support issue.

The request path must not imply that a future extension is already reviewed or
that the user should paste credentials into a public issue.
