# Publish immutable Catalogue snapshots without commits to main

[Decisions #15](https://github.com/bcgov/agent-marketplace/issues/15), [#26](https://github.com/bcgov/agent-marketplace/issues/26) and [v1](https://github.com/bcgov/agent-marketplace/issues/7) choose one serialized publisher that compares meaningful content, creates CalVer full-SHA tags and exact release assets, and builds Pages around those bytes instead of committing generated projections to main. This removes the write-back credential/loop while keeping Catalogue source, current site build, release and deployment evidence independent; docs-only rendering reuses accepted bytes, and current withdrawals cannot be undone by historical asset replay. [Operations](../../OPERATIONS.md#exact-revision-recovery) describes guarded recovery and [#43](https://github.com/bcgov/agent-marketplace/issues/43) holds live controls, immutability and credential-retirement proof; stable Extension identity remains defined in the [glossary](../../GLOSSARY.md) and Reference.
