# Separate administration, Specialty content and Security policy ownership

[Decisions #14](https://github.com/bcgov/agent-marketplace/issues/14), [#16](https://github.com/bcgov/agent-marketplace/issues/16) and [v1 amendments](https://github.com/bcgov/agent-marketplace/issues/7) place registry/engine/workflows/general configuration with Admins, Specialty content with its registered team, and blocking policy/fixtures exclusively with Security instead of hiding conflicting review responsibilities in one configuration file. Generated committed CODEOWNERS requests those owners while Community maintainers remain contacts and trusted-base eligibility inputs rather than mandatory approvers; reviewed Specialty transfers preserve stable identity across ownership changes. [Operations](../../OPERATIONS.md#ownership-and-onboarding) defines onboarding, restoration and sole-owner coverage without waiving hard gates, and [#43](https://github.com/bcgov/agent-marketplace/issues/43) proves the intended review controls.
