Select the revision

Latest published means the accepted Catalogue snapshot served on Pages. Its full source SHA pins the package; the snapshot tag identifies the Catalogue asset. Latest source links to mutable main and can differ from publication. A source preview is labelled as a preview. Publication remains disabled pending activation evidence; an old production schema is unavailable as current v1 data.

  1. Read the record's lifecycle, all replacement notices and declared access. Alias lookups require explicit canonical selection; they never authorize an overwrite.
  2. Download the displayed full-SHA source and compare the complete package inventory and digest, then each mapped native file's SHA-256. A pinned URL alone does not verify downloaded bytes.
  3. Inspect every destination and collision. Explicitly copy only mapped native files; keep skill resources together. The marketplace Manifest is not installed.
  4. Compare installed bytes with the listed SHA-256 values. Preserve unrelated guidance. No package script is executed by the placement helper.

Use the finder

The portable bcgov-find-extension skill searches the published BC Gov Catalogue for a task, offers at most three matches and explains the same choices. Install its full-SHA native package using the preceding steps; portable companions do not require a marketplace checkout. bcgov-create-extension supports authoring. Neither companion provides a separate universal installer.

For repository developers, the actual helper commands below use the shared native map. Run them from a tooling checkout with Python and uv. Review the displayed exact identity, SHA, scope and paths before confirming.

uv run python scripts/find_extension.py search "review a runbook" --extension-type instructions
uv run python scripts/find_extension.py install bcgov-public/instructions/runbook-review-evidence --project /path/to/project --expected-revision FULL_SHA
uv run python scripts/find_extension.py verify bcgov-public/instructions/runbook-review-evidence --project /path/to/project

FULL_SHA is the selected 40-character lowercase source revision. Skill personal placement uses --scope global --home /path/to/home. Project scope is the default. --yes confirms that invocation's displayed plan; it does not bypass revision, lifecycle or integrity checks.

Update and remove

Select the desired published revision, retain the old matching Catalogue for comparison, and review the diff. Updates require unchanged installed old bytes and the same canonical identity/scope. A changed source repository or path also requires explicit --allow-migration. Edited files and collisions require manual review.

uv run python scripts/find_extension.py --catalog selected-catalog.json install bcgov-public/skill/example --project /path/to/project --previous-catalog old-catalog.json --expected-revision FULL_SHA
uv run python scripts/find_extension.py --catalog old-catalog.json remove bcgov-public/skill/example --project /path/to/project

Explicit historical selection checks current notices. A known current withdrawal blocks installing an old active pin. Failed current lookup reports uncertainty without silently substituting cached data; default current lookup fails closed. Historical pre-v1 inspection has no install actions. Removal can use the old explicit native map after withdrawal, but deletes only matching unchanged files and empty skill directories. For edited files, inspect and remove the exact native paths manually. The marketplace cannot remotely revoke installed copies. See lifecycle and identity.
