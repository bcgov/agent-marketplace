Installing from this catalog

After checking a record's declared access and immutable source, install its exact path and revision. APM is preferred because it records the dependency and resolved bytes in a lockfile.

apm install \
  bcgov/agent-marketplace/skills/<specialty>/<skill-name>#842241b962849ad239e1e9c90589b6bc9c881e53 \
  --target copilot

If APM is unavailable, the finder offers a pinned npx skills@1.5.23 command and recommends installing APM for future dependency and lockfile management. Both paths require confirmation.
