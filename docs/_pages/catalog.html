Installing from this catalog

Select any row above to get its exact, pinned install command with a one-click copy button. APM is preferred because it records the dependency and resolved bytes in a lockfile. For example, to install Repo Hardening into the current project:

apm install bcgov/agent-marketplace/skills/security/repo-hardening#{{PUBLISHED_REVISION}} --target copilot

If APM is unavailable, the same panel offers a pinned npx skills@{{INSTALLER_VERSION}} command. The marketplace finder recommends installing APM for future dependency and lockfile management. Both paths require confirmation.

Use the marketplace companions to search this catalog from an ordinary-language Copilot request. The machine-readable catalog.json includes both published records and the approved third-party discovery-source registry.
