Install an Extension

The supported path starts with the two marketplace companions. They make reviewed discovery, capability presentation, immutable source inspection, installation locks, and third-party registration available inside ordinary GitHub Copilot requests.

Install the marketplace companions

Reviewed BC Gov skill

  1. Ask Copilot to find a skill for the task.
  2. Compare at most three deterministic matches. Each includes why it matched, owner, capabilities, review evidence, full source revision, and digest.
  3. Select project scope and inspect the exact destination, source revision, digest, and material capabilities.
  4. Confirm the install. The finder prefers APM and reports apm.lock.yaml; when APM is unavailable it uses the catalog-pinned npx skills fallback and reports skills-lock.json when created.

Third-party candidate

When no BC Gov result fits, the finder searches every approved discovery source. A selected result is resolved to a canonical GitHub repository, full commit SHA, and package path before it enters isolated staging.

i
Candidate files are treated as untrusted data during inspection. The scanner does not load their instructions into Copilot and does not execute contributed scripts.
  1. Review the candidate's source, package contents, and structured capability evidence.
  2. Confirm public marketplace registration. The finder creates or links one deduplicated issue labeled Unreviewed candidate.
  3. Trusted CI fetches the immutable source, computes its digest, and scans it without executing package scripts.
  4. Install only after reviewers publish the exact revision and digest in the BC Gov catalog.

Locks, receipts, and recovery

APM records installs in apm.yml and apm.lock.yaml; the fallback installer may write skills-lock.json. Registration evidence includes source, full revision, path, CI-computed digest, policy findings, capabilities, and issue result.

Ask Copilot to verify installed marketplace skills against the installer lock and selected catalog evidence. A registration failure does not remove or relabel a local installation; retry registration independently.

Direct install

Every catalogue record has its exact, pinned install command with a one-click copy button. Open the catalogue, select a record, and copy the command from the evidence panel. For example:

apm install bcgov/agent-marketplace/skills/security/repo-hardening#{{PUBLISHED_REVISION}} --target copilot

If APM is unavailable, the panel offers an equivalent pinned npx skills@{{INSTALLER_VERSION}} command against the immutable GitHub tree. Direct installation does not submit a third-party candidate for marketplace review.
