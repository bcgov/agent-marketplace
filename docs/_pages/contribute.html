Contribute an Agent Asset

The creation companion owns the path from an idea in any workspace to a review-ready draft pull request. The contributor does not need a marketplace checkout, Python, or uv.

Turn this workflow idea into a BC Gov agent asset and prepare a draft pull request.

What it does

  1. Searches the BC Gov catalog and every approved upstream source for equivalents.
  2. Asks which local files may become public and excludes sensitive or unselected material.
  3. Creates a skill, prompt, instruction, or agent definition with closed marketplace metadata in an isolated staging directory using the hosted specification and schema.
  4. Inventories public files and capabilities and performs a local content inspection without executing package scripts.
  5. Shows one preview containing upstream evidence, public files, capabilities, destination, known findings, and checks deferred to CI.
  6. After confirmation, uses an available GitHub integration or temporary checkout to open a draft pull request.
  7. Uses protected-branch CI as the authoritative schema, policy, test, and generated-output validation loop.

Install bcgov-create-extension

Package contract

skills/<community-or-specialty>/<name>/
├── SKILL.md
└── bcgov-extension.yaml

prompts/<community-or-specialty>/<name>/
├── prompt.prompt.md
└── bcgov-extension.yaml

instructions/<community-or-specialty>/<name>/
├── instructions.instructions.md
└── bcgov-extension.yaml

agents/<community-or-specialty>/<name>/
├── agent.agent.md
└── bcgov-extension.yaml

Hosted packages use Apache-2.0 and IDs of the form bcgov-public/<name>. Metadata declares prerequisites, capabilities, and optional author-declared harness exclusions. An exclusion list is not a compatibility test. Authors cannot set review fields. The installer automates skills only; other types use explicit manual import guidance.

Authors must be members of the GitHub bcgov organization. This is an eligibility proxy, not employment verification. The workflow accepts only PRs GitHub identifies with the MEMBER author association; otherwise it blocks the PR.

Publication boundary

!
The companion cannot approve, merge, assign human review evidence, or transfer evidence to changed bytes. CI and required reviewers decide publication for the exact pull-request revision.

If GitHub integration, branch access, or commit signing is unavailable, staged work is preserved and the companion provides the access or recovery action. Forks are not used for submission.

Manual contribution

Marketplace maintainers working directly in this repository follow CONTRIBUTING.md. This optional local path uses the repository's Python and uv toolchain. Clone the repository once:

git clone https://github.com/bcgov/agent-marketplace.git && cd agent-marketplace && make setup

Then regenerate the catalogue and run the full gate before opening a pull request:

make generate && make verify
