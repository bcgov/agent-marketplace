Pipeline & Governance

The marketplace is repository-backed and statically generated. Publication is a protected GitHub merge, not an application deployment or registry push.

The single required results job aggregates every PR gate. Validation reads contributed package files as data and never executes their scripts.

Generated record

scripts/marketplace.py validates the closed manifest, scans package bytes, inventories every file, calculates a package-tree SHA-256 digest, and produces both catalog/catalog.json and escaped website cards. Centrally controlled source, review evidence, and approved third-party discovery sources are added during generation; authors cannot provide them.

Federated intake

The finder registers one issue fingerprinted by repository, full commit SHA, and package path. The issue workflow independently downloads that immutable candidate, computes its digest, and scans it as data. Unapproved sources, malformed intake, a supplied digest mismatch, or blocking policy findings fail closed. Human review remains asynchronous and only published records enter default discovery.

Operations

Marketplace owners can quarantine or remove a record by lifecycle state, regenerate projections, publish receipt-based removal guidance, and roll back to a previously reviewed immutable revision. See the operations runbook and private reporting route.
