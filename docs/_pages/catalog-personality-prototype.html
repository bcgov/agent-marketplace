How to judge an Extension

Possible maturity markers: draft, active, deprecated. These are lifecycle states, not game levels.

  • Review evidence, not “verified safe”
  • Published revision, not install counts
  • Maintainer contact, not a leaderboard

A streak badge would require stable, opt-in contributor identity and meaningful eligible events; it is deliberately not shown here.
