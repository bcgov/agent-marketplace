Getting Started

This repository provides two BC Gov marketplace workflows for GitHub Copilot: bcgov-find-extension and bcgov-create-extension.

Prerequisites

  • A GitHub Copilot version that supports Agent Skills.
  • Network access to the hosted marketplace catalog.
  • APM, or Node.js with npx, only when installing a published skill.
  • GitHub authentication only when registering a candidate or submitting a draft pull request.
i
The companion skills do not require a marketplace checkout.

Available workflows

Finder
bcgov-find-extension searches generated catalog records and presents installation evidence.
Creator
bcgov-create-extension routes extension types, scaffolds active candidates, analyzes, previews, and submits after confirmation.
Source
Immutable companion packages under skills/community/ in the hosted marketplace repository.

Install the companions

{{RELEASE_BANNER}}

Install the two companions once per device with the -g (global) flag so they are available in every workspace, not just the current project. They install immutable bytes pinned to the published release tag; the exact commit revision and each package content-digest are recorded in the install lockfile, which is what the installer verifies. APM is preferred because it records a manifest and lockfile:

apm install -g \
    bcgov/agent-marketplace/skills/community/bcgov-find-extension#{{RELEASE_TAG}} \
    bcgov/agent-marketplace/skills/community/bcgov-create-extension#{{RELEASE_TAG}} \
    --target copilot

The -g flag installs to your user scope (~/.apm/) instead of the current project, so you run this once rather than in every repository. If APM is unavailable, use the catalog-pinned Skills CLI:

npx skills@{{INSTALLER_VERSION}} add \
    https://github.com/bcgov/agent-marketplace/tree/{{RELEASE_TAG}} \
    --skill bcgov-find-extension --skill bcgov-create-extension \
    --agent github-copilot -y

Verify the install

Two checks confirm the companions are present and intact:

  1. Integrity: run apm audit. It scans installed primitives for drift, hidden Unicode, and lockfile or policy violations, and reports any file that no longer matches its locked bytes. 
    apm audit
  2. Availability: in any workspace, ask GitHub Copilot the prompt below. If it runs the finder, the companion is installed. If nothing happens, re-run the install command above. 
    Use bcgov-find-extension to search for a repository hardening skill.
i
apm list only shows scripts in the current project, so it does not confirm a global companion install. Use the two checks above instead.

Use the workflows

From any workspace, ask GitHub Copilot:

Finder

Find me a BC Gov extension for hardening GitHub Actions.

Creator

Turn this workflow idea into a BC Gov extension and prepare a draft pull request.
!
These workflows assist discovery and submission but do not approve, merge, or assign marketplace review status. Installation and submission require explicit confirmation.
