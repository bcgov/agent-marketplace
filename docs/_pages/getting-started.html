Getting Started

This repository provides two BC Gov marketplace workflows for GitHub Copilot: bcgov-find-extension and bcgov-create-extension.

Prerequisites

  • A GitHub Copilot version that supports Agent Skills.
  • Network access to the hosted marketplace catalog.
  • APM, or Node.js with npx, only when installing a published skill.
  • GitHub authentication only when registering a candidate or submitting a draft pull request.
i
The companion skills do not require a marketplace checkout, Python, or uv. Those tools are used by marketplace maintainers and trusted CI.

Available workflows

Finder
bcgov-find-extension searches generated catalog records and presents installation evidence.
Creator
bcgov-create-extension routes extension types, scaffolds active candidates, analyzes, previews, and submits after confirmation.
Source
Immutable companion folders under .github/skills/ in the hosted marketplace repository.

Install the companions

Use the published marketplace revision. APM is preferred because it records a manifest and lockfile:

apm install \
    bcgov/agent-marketplace/.github/skills/bcgov-find-extension#<published-commit-sha> \
    bcgov/agent-marketplace/.github/skills/bcgov-create-extension#<published-commit-sha> \
    --target copilot

If APM is unavailable, use the catalog-pinned Skills CLI:

npx skills@<catalog-installer-version> add \
    https://github.com/bcgov/agent-marketplace/tree/<published-commit-sha> \
    --skill bcgov-find-extension --skill bcgov-create-extension \
    --agent github-copilot -y

Use the workflows

From any workspace, ask GitHub Copilot:

  • Finder: “Find me a reviewed BC Gov extension for hardening GitHub Actions.”
  • Creator: “Turn this workflow idea into a BC Gov extension and prepare a draft pull request.”
!
These workflows assist discovery and submission but do not approve, merge, or assign marketplace review status. Installation and submission require explicit confirmation.
