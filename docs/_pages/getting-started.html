Getting Started

This repository provides two BC Gov marketplace workflows for GitHub Copilot: bcgov-find-extension and bcgov-create-extension.

Prerequisites

  • A GitHub Copilot version that supports Agent Skills.
  • Network access to the hosted marketplace catalog.
  • A way to download native files and compare SHA-256 hashes.
  • GitHub authentication when submitting a pull request.
i
The companion skills do not require a marketplace checkout.

Available workflows

Finder
bcgov-find-extension searches generated catalog records and presents installation evidence.
Creator
bcgov-create-extension routes extension types, scaffolds active candidates, analyzes, previews, and submits after confirmation.
Source
Immutable companion packages under skills/community/ in the hosted marketplace repository.

Install the companions

{{RELEASE_BANNER}}

Open the Catalogue entries for bcgov-find-extension and bcgov-create-extension, and select their tested manual skill choices. The companions do not require a marketplace checkout. Use the full source SHA in the latest published Catalogue, download each native skill directory and its resources, and compare the file hashes.

For project scope, explicitly place the directories at .github/skills/bcgov-find-extension/ and .github/skills/bcgov-create-extension/. For personal/global scope, choose the tested skill option under your home directory: ~/.copilot/skills/<name>/. Inspect collisions before writing. Keep resources beside SKILL.md and omit the marketplace Manifest. Compare installed hashes, then open VS Code Local and check the customization list. Client discovery depends on its settings/session; placement tests do not establish runtime quality.

No apm install or npx skills add action is advertised until its exact published layout and scope are tested. Other Extension types use tested project choices only. See installation, updates, removal and verification.

Use the workflows

From any workspace, ask GitHub Copilot:

Finder

Find me a BC Gov extension for hardening GitHub Actions.

Creator

Turn this workflow idea into a BC Gov extension and prepare a draft pull request.
!
These workflows assist discovery and submission but do not approve, merge, or assign marketplace review status. Installation and submission require explicit confirmation.
