# BC Gov Agent Marketplace

Shared language for the marketplace's extension catalogue and contribution model.

## Language

**Catalogue**:
A curated, searchable listing of published BC Gov extensions and approved External sources.
_Avoid_: Repository

**External source**:
A third-party collection approved for discovery, not a BC Gov review of each Extension it lists.
_Avoid_: BC Gov vetted marketplace

**Extension**:
A shareable unit of agent customisation (a skill, instructions, prompt or agent) published in the Catalogue.
_Avoid_: Package, plugin, asset

**Plugin**:
A curated, installable collection of Extensions assembled for a specific workflow.
_Avoid_: Extension, automatic bundle

**Manifest**:
The marketplace metadata an author declares alongside an Extension's content: its maintainers and capabilities, plus any overrides of derived defaults.
_Avoid_: Sidecar, config

**Specialty**:
A named domain area whose extensions are owned and governed by a domain team.
_Avoid_: Category, path
