# External-source boundary

V1 searches BC Gov Extensions only. The Catalogue approved-discovery-sources
field supplies site links to configured External sources; those links do not
authorize item search, recommendation,
candidate registration or installation by this skill. Those capabilities and
plugin packaging are deferred. A source link is not per-item scan evidence.

If BC Gov has no match after query refinement, report the gap and offer direct
help or the creator's local authoring workflow. Do not invent a matching record.
