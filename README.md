# BC Gov Agent Marketplace

[![Publish](https://github.com/bcgov/agent-marketplace/actions/workflows/publish.yml/badge.svg)](https://github.com/bcgov/agent-marketplace/actions/workflows/publish.yml)

Share skills, instructions, prompts and agents through the [Catalogue](https://bcgov.github.io/agent-marketplace/catalog.html).
[Install](https://bcgov.github.io/agent-marketplace/install.html), [Contribute](https://bcgov.github.io/agent-marketplace/contribute.html) and [Reference](https://bcgov.github.io/agent-marketplace/reference.html) explain the four-type contract.

V1 implementation is dormant: publication and both automatic merge routes are off. [#43](https://github.com/bcgov/agent-marketplace/issues/43) records administrator activation and live evidence; genuine non-writer browser contribution evidence remains tracked in [#48](https://github.com/bcgov/agent-marketplace/issues/48). A workflow badge describes run status, not successful publication or deployment. Until v1 reaches main and Pages, published pages/data may still describe the previous version.

Developers start with [CONTRIBUTING](CONTRIBUTING.md). Administrators use [OPERATIONS](OPERATIONS.md); private vulnerability reports follow [SECURITY](SECURITY.md). [Domain vocabulary](GLOSSARY.md), [architecture decisions](docs/adr/0001-author-declared-harness-readiness.md) and [preserved research](docs/research/README.md) retain the reasoning behind the design.
